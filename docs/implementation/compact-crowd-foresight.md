## NSC
Fixture rankings: Upcoming / Live / Past, default Following with All sports and sport filters. Upcoming next seven days, Past previous seven days, selectable ranges; Live current fixtures. Rows show fixture, time/status, score and voter count; My NSC holds points/profile/leaderboard/settings. Public summaries use equal-weight real users including viewer, latest vote per phase, no simulation/Like/persona weighting. Live latest vote per person in preceding 15 minutes, no stale score. Rank at five voters by unrounded mean then count/time/ID; Early ratings below ranked entries, unrated last. Public read, existing contribution eligibility. Standard Feed: Crowd x/5 and five one-tap Your rating blocks. No Events ratings UI, no Compact ratings. Past crowd scores are spoiler-safe. Poll visible live values every30s/resume, offer ranking refresh without moving rows.

Corrections allowed within phase; all live fixtures eligible without activated session. Tooltip exact strings: Rate how you think it'll go / Rate how it's going / Rate how it went. Immediate fill, pending/error state, animate confirmed award only. Existing Heat2/Pulse1/Impact3 participation once; foresight supersedes final Heat total. Same-value live vote refreshes freshness. API owns phase, aggregates, paging and idempotent transactions.

## Foresight
Prediction minimum2 points, accurate4 total, accurate contrarian8 total, symmetric positive/negative. Latest pregame revision counts, each revision records timestamp and benchmark, lock at kickoff. Expected enjoyment=(versioned algorithm forecast + other-user pregame mean)/2, never stakes as enjoyment. Accurate error<=0.5; contrarian distance>=1 and improvement over expectation>=0.5. Outcome excludes predictor. Settle48h after confirmed completion with>=5 other Impact voters; retry until7d then unscored. Contrarian requires>=5 other pregame voters and valid algorithm forecast; ordinary accuracy still possible otherwise. Initial2 immediately, bonus2/6 after settlement; no bonus for cancellations or duplicates. Bonuses exempt participation caps. Auditable immutable settlements, revisions, progress and server-ledger award acknowledgement. Accuracy/reliability metrics separate from participation points; evaluate surfacing influence offline before enabling.

Configurable server-owned privilege thresholds and prize campaigns; automatic eligible entries/unlocks, deduplicated. No score weighting/admin rights from privileges. No invented prize, eligibility promise or live campaign before actual terms/rewards configured.
