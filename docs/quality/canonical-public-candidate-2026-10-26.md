--candidate-output=/absolute/new-directory` in a clean environment. Node itself
interprets preload settings before application preflight can refuse them.
Only `target: quick:nbl` and `provenance: constructed-fixture` are qualified.
The input names one exact public NBL URL, fixed response filename, body hash,
byte limits and original observation clock. Strict public schemas reject
unknown fields and nested values in scalar slots. Private/managed/deployment
credential keys, combined/default/release flags and symlinked inputs refuse
before staging. Constructed provenance is not source authenticity/currentness.

Source content/modes are checked against committed Git blob IDs, copied into
private scratch and checked again. Only tracked public application/source files
enter the clone; no original `.git`, ignored environment, private Follow input
or runtime file enters it. Reuse only the already-installed pinned pure-JS
Terser5.44.0 dependency; no runtime/package install or download occurs.

## Review package and failure

A changed replay creates a deterministic local branch/commit in a private
object store, immutable thin `candidate.bundle`, validated local staging intent,
source/dependency hash manifest and handover. Identical input/source produces
the same diff, branch, revision and bundle. No remote push or managed write is
performed. An unchanged replay reports `unchanged-fixture-replay`, with no
bundle or empty review commit.

Handover binds the consumed input hash, source SHA, original observation,
constructed provenance, changed paths/hashes, actual status/signal, sticky
ledger, measured limits and bounded sanitized refresh/quick reports. Missing
result IDs/fields, source failures, failed step and failure chain survive
scratch removal. Failure removes bundle and staging intent; cleanup/reporting
must retain the first refusal. Tests remove only their owned scratch/clones;
no whole-workspace preimage is retained.

DEPLOY's existing authorised client must independently validate the handover,
manifest, bundle prerequisite/hash, exact diff inventory and source ancestry,
then create a tested draft PR and issue28 queue entry through existing access.
The preparer has no PR/main/deploy credential and cannot accept itself. Local
deterministic identity helps deduplication; uncertain remote dispatch and actual
queue discovery/intake still require qualification.
