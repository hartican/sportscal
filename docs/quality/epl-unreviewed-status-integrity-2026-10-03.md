# EPL unreviewed status admission — 3 October 2026

The EPL reader previously converted every missing or unrecognised raw status into a freshly checked upcoming fixture. A controlled mutation of one saved real upcoming fixture reproduces this for an unreviewed QA value, missing status, null and blank status. No current real-source corruption was found: the saved 380-fixture season contains 50 completed `C` and 330 upcoming `U` records. The shipped repair admits those reviewed codes and preserves last-good data when a different value appears. It does not complete live or non-playing status support, Football certification or the wider CTO programme.

## Boundary and failure behaviour

Status admission runs on each received page, the complete collection and the direct card entrypoint. An unsupported first page stops before another provider request. No raw status is normalised by guessing its meaning or inferred from kickoff time. Existing four-page/request and network deadlines remain.

Canonical refresh retains its existing delayed-backup recovery: a complete validated backup may add an explicitly finished result to an existing known fixture. Failed or conflicting recovery keeps prior facts and original source dates. The existing live owner records a generic source failure and publishes no new observation; it gains no backup path. Real unsupported live/non-playing codes will therefore retain older facts until verified mappings are implemented. This limitation stays explicit rather than manufacturing upcoming freshness.
