# Shared layout notes

These explanatory notes were moved out of the shipped stylesheets on 4 October 2026 to retain the existing compressed-shell budget. CSS rules and their order are unchanged. This is context, not a new release procedure.

## assets/styles/nothingsport-foundation.css

- Shared app chrome: one action accent, one control rhythm, sport colour only where it identifies a code, club or athlete.

## styles/follow-feed-rework.css

- One shared layout contract for Feed, Events, Follow and NSC.
- L0 has its own geometry. No hero dimensions or second identity placeholder.
- Text enlargement gets a readable second line instead of an invisible name.
- Follow keeps this track mounted; only directory content is replaced.
- Shared, one-tap rating control.
- NSC is a page with one Back path, not a side drawer.
- One body-level viewport anchor owns both timeline controls.
- Shared Feed timing mark: normal flow reserves space for long labels.
- Feed composition: equal opponents, one clock, then the fixture's own rating.
- Nation ties have no player portrait: do not reserve an empty hero frame.
- Bound each Schedule identity to its grid track, including unavailable artwork.
- Keep all marks optically legible without changing their official artwork.
- Retry replaces the pending rating message without moving the flames.
- Identity corrections use the same full-card frame; list marks remain unchanged.
- A single owner for Follow navigation keeps all sport controls reachable.
- All fixture layouts stack the local date above the clock.
- Optional fantasy enrichment: no row or space exists until verified.
- Favourites stay one tap away while a long sport directory is scrolled.
