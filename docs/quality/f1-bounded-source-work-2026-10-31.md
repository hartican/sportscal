# Bounded F1 result recovery — 31 October 2026

The existing canonical `update-cards.js --f1-results --local-only` route uses
its existing quick owner's atomic snapshot, retained publisher and derived
builders. It adds no entrypoint, provider, database operation, account access,
scheduler or release lane. ROOT/nsDEPLOY owns actual-source allocation,
integration, generated output adoption and publication. Local constructed
controls are not current-provider, native, deployed or physical-device proof.

## Sporting contract

Use the exact individually reviewed United States Practice 3, Qualifying and
Race classifications, and Mexico Practice 2 classification. Their checked-in
source witnesses bind retained ID, canonical identity, original sporting start,
exact official URL and heading, and the entire ordered driver/number/team/
position/classification set. This is a limited current-source contract, not a
universal twenty-two-driver assumption or independent FIA entry-list proof.
The twenty-three-name retained season catalogue is not an entry list.

Capture metadata and hashes distinguish saved extracted web documents from the
manually copied full visible United States race classification table. Neither
is raw HTML or HTTP completeness proof. Test HTML is explicitly constructed
from those entry-set facts; it is not a provider capture. The real response
must later match the reviewed set and pass bounded complete-body/parse checks.

Mexico Practice 1 has ten unbound reserve/rookie participants. Report it as a
card-local deferral without requesting it, admitting new participants, dropping
rows or substituting regular drivers. Preserve seven older pending sessions
outside the existing seven-day window. Recalculate eligibility and practice's
ninety-minute delay on every invocation. Missing later session witnesses defer
their own cards; they never authorize a guessed field or a wider query.

Reject ambiguous retained identities, disagreeing sporting starts, conflicting
retained finals and invalid/future selected observations before source work.
An incomplete/changed individual classification or unavailable session HTTP
response retains that card beside supported independent results. An explicit
no-result page stays pending and cannot retract a final. Global integrity,
transport resource limits, complete Feed, spoiler and build gates stay strict.

## Resource and preservation contract

Read the exact official 2026 results index first. Only its explicit GP links
can authorize the selected session URLs; numeric GP IDs must also match the
reviewed witnesses. No retry, redirect, guessed GP ID or extra session. The
current maximum is five GETs (index plus four supported sessions), within the
original six-GET cap. Shared invocation memoization reuses each complete
resource across the two retained Feed surfaces.

The private HTTPS reader checks fifteen seconds across each resource's headers,
body, decompression, strict UTF8 decoding and synchronous source parsing. Wire
and decoded bodies each have a one-MiB resource cap and six-MiB invocation cap.
Body receipts include actual URL, observation, byte counts and wire/decoded
SHA256 hashes; receipt of a body is separate from sporting admission. Parse
failures retain cancellation ownership until request/response/decoder disposal.

The canonical owner gives source/projection work at most 110 seconds, reserving
ten seconds inside the 120-second invocation allowance for rollback. Every
projection child receives the remaining work timeout. Expiry rejects the
candidate. Cleanup still attempts every restoration; a cleanup beyond the
outer deadline is explicitly failed, never accepted as a timely rollback.
Controlled clocks prove those branches, not native filesystem latency.

Read all candidate facts before writing. Independently patch incoming and
published records from their own current facts, viewing, writing and genuine
clocks. The private exact-ID receipt selects only changed cards on each surface
for normalization/editorial reconciliation; stitch every other record back in
its original order and fields. An unchanged counterpart has an empty selector.
Existing full Feed and spoiler validation still inspect the stitched result.
Scoped F1/motorsport and shared dependent outputs rebuild through existing
builders. Any mandatory failure restores data/Feed and all eight runtime files,
removes new outputs and retains the original error before fallible diagnostics.
