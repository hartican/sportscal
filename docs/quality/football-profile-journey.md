# Football profile journey — 30 September 2026

Shell 335 production reproduction found that closing a fixture participant profile left focus on the document body. The EPL alias `premier-league` missed the Football directory and table. The common Football context path rendered all 92 standings rows across three competitions with Results off. The latter was reproduced by exercising the common profile context path; it was not visible in the broken EPL alias path.

The repair resolves a fixture's Football Code before opening its directory, limits the table to that fixture's competition, and requires an explicit profile-only reveal while Results is off. Directory-only entry uses competitions containing the participant or sourced current team. Source dates, source links and provisional table notes remain visible after reveal. A failed table fetch offers a scoped retry. No rank or result is invented.

Closing via Close, Escape or same-URL browser Back restores the original route, current participant control and card position. Instrumentation showed a later Feed render could replace an already focused button. A return anchor now tracks list replacement/layout only until the next user interaction, outside focus, route change or page hide; it then disconnects. It does not re-add excluded fixtures or change follows, ratings or Results. Tab and Shift+Tab stay within the modal. Profile opening is deferred with the existing optional module; no startup request was added.
