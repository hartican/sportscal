# SailGP identity and venue panels

The complete current official landscape marks are saved unchanged for light/dark identity slots. Original SailGP rights remain; editorial identification only, no open licence asserted. Individual source URLs, hashes and modifications are in asset-manifest.json. Footer and About credit SailGP.

The first-party sailing SVG uses the existing vector-asset paths with a transparent background. No day-specific course/venue geometry has been verified. A country outline is not a race-course map. Panels therefore show this glyph and say Course unverified, using reviewed F1 country palettes or a neutral panel. Events parents do not gain ratings.

Calendar facts are reviewed edition-specific organiser snapshots, ingested only through scripts/update-cards.js --sailgp-venues -p or the ordinary owner. This is not an unattended public-site scraper, new result/live source or broader source certification. Preserve existing IDs, original result and Geneva timing observations, no inherited future entry or viewing claims, and both source failure/unchanged replay contracts.
